# Game Alpha

Versão alpha de um jogo em desenvolvimento que combina elementos visuais e mecânicas em 2D e 3D, trazendo uma experiência inspirada em *A Hat in Time* e *Slime Rancher*. O projeto busca explorar diferentes possibilidades de gameplay, misturando exploração, plataformas e interação com o ambiente. Ainda em fase inicial de desenvolvimento, o jogo está passando por testes e melhorias em suas mecânicas, movimentação e identidade visual, com o objetivo de construir uma experiência divertida e original.
